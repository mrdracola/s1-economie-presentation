## Five-Step Method

1. Diviser la tâche en différentes parties.
2. Attribuer un temps à chaque partie.
3. Ajouter une marge de sécurité de 5 %.
4. Établir un échéancier précis.
5. Organiser les horaires dans l'agenda.

## Visual Art Direction

### Principles
- Elegant, minimal, academic, modern, sophisticated.
- Strong typography hierarchy — readable on a classroom projector.
- Generous whitespace. Cinematic but restrained.
- No generic dashboard aesthetics.
- No excessive rectangular cards.
- No unnecessary gradients.
- No neon effects. No visual clutter.

### Color Palette

| Token | Hex | Usage |
|---|---|---|
| `--color-deep-navy` | `#071827` | Slide backgrounds (dark) |
| `--color-primary-navy` | `#10243A` | Secondary backgrounds, surfaces |
| `--color-teal` | `#13B8A6` | Primary accent, highlights |
| `--color-orange` | `#F59E42` | Secondary accent, callouts |
| `--color-off-white` | `#F8FAFC` | Body text on dark |
| `--color-white` | `#FFFFFF` | Pure white |
| `--color-muted` | `#64748B` | Muted text, secondary labels |

### Typography

| Language | Font | Fallbacks |
|---|---|---|
| French / Latin | Inter | system-ui, Segoe UI, sans-serif |
| Arabic | Cairo | Noto Sans Arabic, Tahoma, sans-serif |

### Layout
- Slide aspect ratio: **16:9**
- Slide padding: `5% 6%` (top/bottom / left/right)
- Content max-width: `1280 px`
